# Security Policy

## Supported scope

This repository is a portfolio and learning project. It is designed to demonstrate secure architecture, security engineering practices, testability, and defensive control design.

## Responsible use

Use this project only in systems, labs, and environments where you have authorization. Do not use this repository to bypass controls, collect credentials, evade detection, or target third-party systems.

## Reporting security issues

If you identify a security issue in this repository, please open a GitHub issue with a clear description, reproduction steps, and suggested remediation. Do not include secrets, credentials, private keys, personal data, or exploit payloads in public issues.

## Security expectations

- Keep examples safe and non-destructive.
- Prefer least privilege in scripts, workflows, and configuration.
- Add or update tests when changing security logic.
- Document assumptions, limitations, and safe-use boundaries.
